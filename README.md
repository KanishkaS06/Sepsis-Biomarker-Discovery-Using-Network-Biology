Network-Based Identification of Candidate Biomarkers in Sepsis
Overview

This project explores a publicly available sepsis transcriptomic dataset to identify candidate biomarkers using an integrated bioinformatics workflow.

The project was conducted as a self-directed learning exercise to understand how researchers perform biomarker discovery using gene expression analysis, network biology, and pathway enrichment approaches.

Workflow
GEO Dataset
    ↓
GEO2R Analysis
    ↓
Differentially Expressed Genes (DEGs)
    ↓
STRING PPI Network
    ↓
CytoHubba Hub Gene Analysis
    ↓
MCODE Module Detection
    ↓
KEGG Pathway Enrichment

Tools Used
GEO2R
STRING
Cytoscape
CytoHubba
MCODE
ShinyGO
Key Findings

Identified 165 differentially expressed genes.
Hub gene analysis highlighted:
S100A8
MMP9
NCF2
ARG1
RETN

MCODE identified a core functional module containing:
S100A8
MMP9
NCF2
ACTB

KEGG enrichment revealed involvement of:
IL-17 signaling pathway
Leukocyte transendothelial migration
Proteasome pathway

Conclusion
This exploratory analysis identified several candidate genes associated with sepsis-related inflammatory processes and provided hands-on experience in network-based biomarker discovery.
