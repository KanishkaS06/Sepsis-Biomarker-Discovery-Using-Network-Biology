This project presents a self-directed bioinformatics analysis aimed at identifying potential biomarkers associated with sepsis using publicly available transcriptomic data. Differentially expressed genes (DEGs) were identified using GEO2R and subsequently analyzed through a protein–protein interaction (PPI) network constructed using STRING and Cytoscape. Hub genes were identified using CytoHubba, functional modules were detected using MCODE, and pathway enrichment analysis was performed using ShinyGO/KEGG. The analysis highlighted key candidate genes, including **S100A8, MMP9, NCF2, ARG1, and RETN**, with enrichment in pathways such as **IL-17 signaling** and **leukocyte transendothelial migration**, suggesting their potential involvement in sepsis-related inflammatory and immune responses. This project was undertaken independently as a learning exercise to gain practical experience in transcriptomic data analysis, network biology, and computational biomarker discovery.
